# Pixstock
A stock media web application built with JavaScript, React, HTML, CSS and API.

## Demo
Check out the live version of the app here: [Live Demo](https://pixstock-silva.netlify.app/)


## Description
Pixstock is a web application that allows users to browse and search for high-quality stock photos. It fetches images from a stock media API, displaying images based on popular categories, search terms, and user preferences. Built with React for dynamic updates and HTML/CSS for the structure and styling.

## Features
- Browse through high-quality stock photos fetched from a media API.
- Search functionality to find images based on keywords or categories.
- View image details such as photographer name, resolution, and more.
- Responsive design for mobile and desktop use.

## Technologies Used
- JavaScript
- React
- HTML
- CSS
- API
